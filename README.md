# Лесенки: Путь наверх

2D платформер с лесенками. Карабкайся вверх по платформам, собирай монеты и звёзды, добирайся до выхода!

## Управление

- **WASD / Стрелки** — движение
- **SPACE** — прыжок
- **W / ↑** — подниматься по лесенке
- **S / ↓** — спускаться по лесенке
- **R** — вернуться в меню

## Запуск

```
pip install pygame
python game.py
```
